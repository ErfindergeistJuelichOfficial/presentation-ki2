# Beispiele aus dem Workshop „KI to 3D“

Alles zu einem Beispiel liegt in einem eigenen Ordner — Bilder, OpenSCAD-Dateien, Prompts und Demos.

| Ordner | Inhalt |
|---|---|
| [openscad-turm](openscad-turm/) | Einfachstes OpenSCAD-Beispiel: Turm mit Dach, alle Maße als Parameter |
| [hexenturm](hexenturm/) | Der Jülicher Hexenturm — mit KI in OpenSCAD konstruiert und gedruckt |
| [tischfuss](tischfuss/) | Praxisbeispiel Ersatzteil: gebrochener Tischfuß, mit KI nachkonstruiert |
| [muttkrat](muttkrat/) | Bild → 3D: Figur mit ComfyUI (Z-Image-Turbo + Hunyuan3D) erzeugt und gedruckt |
| [chihuahua-muffin](chihuahua-muffin/) | Test für multimodale Modelle: Hund oder Muffin? |
| [snake](snake/) | Von KI geschriebenes Snake-Spiel für den Browser |
| [herzanimation](herzanimation/) | Animation für die Termine-Webseite, mit zwei Prompts verfeinert |
| [bildverarbeitung-diagramm](bildverarbeitung-diagramm/) | Vorher/Nachher-Ablaufdiagramm einer Bildverarbeitung |

Die Präsentation dazu: <https://presentations.erfindergeist.org/ki2/>
