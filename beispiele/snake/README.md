# Snake

Ein kleines Snake-Spiel, komplett von KI geschrieben — eine einzige HTML-Datei.

| Datei | Inhalt |
|---|---|
| `snake.html` | Im Browser öffnen und spielen |

**Prompt:** „Baue ein kleines Snake-Spiel, welches direkt im Browser läuft.“

Im Workshop wurde derselbe Prompt einmal im Chat (Web-UI) und einmal mit einem Coding-Agenten ausgeführt.
