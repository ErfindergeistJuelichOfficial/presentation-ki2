# Herzanimation

Pulsierendes Herz-Icon für die Termine-Webseite des Vereins — Beispiel dafür, wie man eine Animation mit zwei kurzen Prompts verfeinert.

| Datei | Inhalt |
|---|---|
| `herzanimation.html` | Im Browser öffnen: links die erste Version (Kreis), rechts nach dem zweiten Prompt (Herzform) |

## Prompts

1. Erstelle im Sponsoring-Bereich ein Herz Icon und nutze die Animation von gsap.com/community/forums/topic/28814-using-gsap-to-loop-a-pulsing-animation/
2. Die Animation vom Herz Icon im Sponsoring-Bereich soll mehr wie ein Herz aussehen.

Hinweis: Die Datei lädt GSAP aus `../../js/gsap.min.js` — am besten aus dem geklonten Repository heraus öffnen.
