# OpenSCAD-Turm

Das einfachste Beispiel aus dem Workshop: ein runder Turm mit kegelförmigem Dach.

| Datei | Inhalt |
|---|---|
| `openscad-turm.scad` | OpenSCAD-Code — in [OpenSCAD](https://openscad.org) öffnen, F5 = Vorschau |
| `openscad-turm.png` | So sieht das Ergebnis aus |

## Prompt (SAND-Methode)

- **S:** Du bist OpenSCAD-Experte. Ich bin Einsteiger und möchte das Modell später selbst anpassen durch Parameter.
- **A:** Erstelle einen runden Turm mit kegelförmigem Dach.
- **N:** Alle Maße als Parameter ganz oben, jeweils mit deutschem Kommentar. Im restlichen Code keine festen Zahlen. Turm grün (#159989), Dach gelb (#F9B338).
- **D:** Eine einzige .scad-Datei, kurz und übersichtlich kommentiert.

**Tipp:** Oben in der Datei z.B. `hoehe = 80;` setzen — der Turm wird sofort höher.
